## 3. Internal Linking Strategy

### Hierarchy
```
Homepage (/)
├── /events/upcoming/          [Events Hub]
│   ├── /events/{event-slug}/  [Individual Events]
│   ├── /hackathons/           [Hackathon Category]
│   ├── /workshops/            [Workshops Category]
│   └── /past-events/          [Archive]
├── /technical-clubs/          [Clubs Hub]
│   └── /technical-clubs/{club-slug}/  [Individual Clubs]
├── /campus-guide/             [Venues]
├── /faq/                      [FAQ]
└── /contact/                  [Contact]
```

### Cross-Linking Rules
1. **Events → Clubs:** Each event page links to the organising club's page
2. **Clubs → Events:** Each club page has an "Upcoming Events" section
3. **Homepage → Events + Clubs:** Hero section with prominent CTAs
4. **FAQ → Events/Clubs:** Answers link to relevant pages
5. **Footer:** Links to all major sections + official BU sources
6. **Anchor text:** Descriptive, never "click here"

## 4. Keyword Cannibalization Prevention

| Risk Pair | Risk Level | Resolution |
|-----------|------------|------------|
| `/events/` vs `/events/upcoming/` | Medium | `/events/` = all events directory; `/events/upcoming/` = time-filtered view. Different intent. |
| `/technical-clubs/` vs individual club pages | Low | Directory page = broad discovery; individual = specific lookup. No cannibalization risk. |
| `/workshops/` vs `/events/` (filtered) | Medium | `/workshops/` = dedicated landing page optimised for workshop keywords; events page = general. Canonical `/workshops/` to itself. |
| `/hackathons/` vs `/events/` (filtered) | Medium | Same as workshops — hackathons page is the SEO-optimised destination for hackathon queries. |

## 7. Competitor Keyword Gaps (Opportunities)

The official Bennett University website (bennett.edu.in) has these notable SEO gaps:
- No dedicated hackathon landing page with structured data
- No searchable/filterable event directory
- No FAQ page addressing student registration questions
- No club-specific pages with activity listings and event history
- No campus venue guide with capacity/description information

**These gaps represent direct keyword opportunities for Bennett Student Hub.**
